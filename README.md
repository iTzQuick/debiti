# Conto alla Rovescia Debiti

App web installabile (PWA) per tenere sotto controllo budget del mese, spese giornaliere, prestiti, spese fisse e obiettivi di risparmio.

**I dati personali non sono in questo repository:** restano salvati solo sul telefono (localStorage) e si spostano con il file di backup dell'app.

## Installare su iPhone
1. Apri il sito in Safari.
2. Menu (≡) → Condividi → **Aggiungi alla schermata Home**.
3. Apri l'app dalla Home → **Carica i miei dati** → scegli il file di backup.

## Aggiornamenti
Ogni modifica pubblicata su `main` va online da sola con GitHub Pages. L'app sul telefono prende la nuova versione alla prima apertura con internet; i dati non vengono toccati.

## Backup
Scheda **Obiettivi → Backup dei dati → Scarica backup**. Farlo a ogni stipendio e salvarlo su iCloud Drive.
